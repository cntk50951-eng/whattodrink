# 2026-09-05: 未經允許不准 push（用戶硬規則）

## 情境

UR1.1 水彩底圖 fix（5d81db7）完成後，我直接 commit＋push 到
`feat/ur1.1-drink-map`，沒有再問用戶。

## 問題

用戶糾正：下次沒有他的允許，不要直接推送 GitHub。

## 原因

之前的「你可以推送」授權只覆蓋當次文案改動那一單；新的改動（底圖換源）
是另一個任務，不能沿用舊授權。push 之前必須有當次明確許可。

## 修正

- 任何 `git commit`／`git push` 之前，先用 AskUserQuestion 拿當次確認，
  即使用戶之前說過「可以推送」——那句只對當次有效。
- 例外：用戶當輪明確說了「push／推送」才可直接動手，且只推他點名的範圍。
