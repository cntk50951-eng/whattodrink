# 介紹頁動態敘事與自然對焦

## 情境
用戶認可 66 張圖片和新增功能，要求更多動態敘事、移除文案 01 等序號，並讓對焦／放大等動畫自然。沿 UR M.1，只改本地 intro-next。

## 問題
原對焦共用快速 ease-out，畫面在放大時換頁且焦點同時移動，光暈亦跟放大同步急增。每幕大致同一種浮動，文字一次出場，操作流程的視覺接力不足。

## 原因
同時插值 scale 和 transform-origin 會產生不直觀的平移；線性 CSS scale 的可見面積不是線性。光效與鏡頭共用 envelope，把強調變成亮度脈衝；缺少頁面交接前退焦與不同場景的運鏡節奏。

## 修正
- 比較增加浮動／光效與按功能步驟安排鏡頭，採後者；沿 glide／arc／lift 配置，頁面 slide／lift／dissolve 平順交接。文字逐行出場、關鍵句下劃線、原流程短語依影格接力強調；沒有新增底部播放器條。
- 五次 smootherstep 保證端點速度／加速度為零；查本機 Remotion 型別和官方 interpolate API 後使用 perceptual-scale。固定中心＋仿射平移，頁面交接前略退焦、在新頁安定後推近。桌面上限 1.5、手機 1.24，光暈獨立慢變化、縮放幅度 6%，不隨每次交接閃亮。
- 三語介紹 eyebrow 和圖片預覽標題去序號；App 圖片的實際步驟、時間、數字保留。66 張圖片不重新生成，原版／iOS／proxy／首頁不動，不提交／推送／部署。
- 所有效果由 Remotion 影格推導，暫停／凍結保持一致；減少動態仍停結尾，手機不承受桌面倍率。原未使用的放大卡／浮動 CSS 已清理。
- 測試覆蓋連續性、退焦與光效解耦、圖片覆蓋邊界、換頁始終有不透明底圖、最多兩頁相交、短語交接與去序號。浮點位移的 -0 與 +0 視覺等價，對零位移用 toBeCloseTo 而非 Object.is。
- CHANGELOG、backlog、素材 README 及 docs/data/intro-marketing.md 同步。本輪沒有暫存檔；使用者仍需在本地親驗動畫自然度。
- 驗證過程：與 build 並行的全量測試中，既有 lib/barDice.test.ts:184 模擬超出 5 秒（其餘 1,225 過）；未改核心骰子或全域逾時，build 完成後單獨重跑全量確認。
- 最終全量重跑 116 檔／1,226 tests 通過；build 132 頁、lint 零錯／12 個既有 warnings；最後本輪 97 項再驗通過。足跡／酒局等文字短語數與圖片頁數不同時，明確 phraseTimes 對齊實際換頁，不能平均切時間。
