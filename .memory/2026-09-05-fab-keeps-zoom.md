# 2026-09-05 — 用戶糾正：speed-dial 不可以食掉縮放

## 背景
UR1.3 把地圖所有操作收進單一 FAB speed-dial 時，順手刪了常駐的放大/縮小按鈕
（假設 pinch 已夠）。用戶即時糾正：縮放按鈕不見了，要回來。

## 教訓
- 「收進同一個按鈕」≠「減少功能入口」。整合的是**位置**，不是**功能數量**。
  刪功能要逐個向用戶確認，不可以搭便車。
- 修法：縮放 +/- 做回扇形第 1、2 個孩子（共 5 個：放大/縮小/睇全香港/
  回到我的位置/隨機推薦），最常用的揀酒放最貼近拇指的最底。
- 主鈕換成手繪啤酒（杯內氣泡無限上升 CSS 動畫）+ 首次提示 pill
  「㩒我揀嘢飲！」（localStorage `wtd-fab-hint` 睇過一次就收），解決「+／X 太醜、
  睇唔出撳得」。
