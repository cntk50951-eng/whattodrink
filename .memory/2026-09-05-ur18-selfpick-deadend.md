# 2026-09-05 — UR1.8 bug：圆圈点选酒没反应＋旧记录消失

## 情境
- 用户报：点当前位置圆圈弹 self 卡，点“随机推荐一杯”没反应；
  且之前的酒类记录消失了。

## 问题
- 两根因，分属不同年代：1）`handleSelfPick` 关卡＋`handlePick`，
  但从 UR1.1 起就没开过 sheet——UR1.1 面板常开所以当时能用，
  UR1.2 抽屉化（默认收起）后这条路静默失效，注释还写着“面板可见”，
  三个 UR 没人发现；2）我 UR1.8 把旧快照退役写进 `handlePick`，
  用户只是 re-roll，旧打卡连 pin 带记录当场被清。

## 原因
- 1）重构改了被依赖的假设（面板常开→抽屉），没 grep 所有依赖方；
  注释写的是旧世界，被当成现状信了。
- 2）“新一轮退役旧记录”想当然：re-roll ≠ 新打卡落地，
  退役点应在真正覆盖发生的 `handleWant`。

## 修正
- `handleSelfPick` 补 `setSheetOpen(true)`，结果落进可见处。
- `handlePick` 只换候选（`setPicked`），旧 pin＋记录＋storage 碰都不碰；
  覆盖只发生在 `handleWant`（同 key 天然覆盖）。
- 铁律：改共享假设（常开→收起、会话→持久）时，grep 所有读写方；
  注释里的现状断言，重构后默认已过期，读到先验证。
