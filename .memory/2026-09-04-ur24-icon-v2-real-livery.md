# 2026-09-04 UR2.4 图标 v1 失真：凭印象+只用主题色画品牌 icon 必翻车

- 现象：用户看 `/preview-beer-icons` 直言"真实度不够，根本没基于真实图片"。
- 根因有二：(1) 凭训练记忆落笔，没查真实包装就画（Asahi 画成米白罐+红日，实物是银罐+藏青字）；(2) frame 注释立了"只用主题色、不抄品牌色"的规矩，10 个 icon 共用一套配色，神似无从谈起。
- 修复：10 个全查真实包装（web_search 逐个确认瓶/罐型、主色、label 构成）再重画 v2；墨线保留主题色 + wobble 笔触保证站内涂鸦一致，填色改用固定品牌 hex。
- 教训：画任何现实产品（包装/地标/人物）前必须先找参照（搜图描述、官网、包装报道），哪怕只是风格化涂鸦；"主题色优先"的全局审美规则遇到"一眼认出"的识别需求时，识别优先——并把例外写进注释。
- 附带：next-intl `localePrefix: 'never'` 项目中新页面路由必须建在 `app/[locale]/` 段内（见 2026-08-24 那条）。
