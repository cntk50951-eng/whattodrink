# 2026-09-27 UR C.10 返工：他人卡容器決策被用戶 DOM 推翻

## 情境

- UR C.10（v2 他人打卡卡升級）：問答定案「A 同構 Sheet，容器不動」（他人留浮動卡，只同構信息行）。

## 問題

- 「容器不動」是錯決策：自家是 bottom Sheet（自帶 absolute X＋grabber＋Header），他人是浮動卡——容器不同，X 與結構「不可能一致」，信息行同構只是表面功夫。

## 原因

- 把「同構」理解窄了（只看到字段，沒看到容器）；用戶要的是同一套容器。X 錯位的根因也在容器（浮動卡 Header 內 X vs Sheet absolute X），同容器即按構造消失，無需逐個調位置。

## 修正

- 他人卡搬進同一 bottom Sheet（open 條件＋onClose＋IIFE early-return 分支；openPin／openWant 互斥一行）；浮動卡整塊刪＋`CardHeader/Title/Description/Separator` import 同刪（`Card` 留給換酒格）。
- 三閘：test 548 綠／lint 零新增／tsc 淨／build 綠；待用戶複驗。
- 教訓：凡「與 XX 一致」的需求，先問容器是否也要同一套；用戶貼 DOM 即實現規格，直接對標，不要隔空猜「亂在哪」。
