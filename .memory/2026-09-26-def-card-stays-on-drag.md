# 2026-09-26 拖圖關卡翻案：卡只走顯式關閉（DEF-20260926-007）

## 情境

好友卡可開後，用戶指正：拖圖卡自動消失，要求只點 X 才消失。

## 問題

UR2.1 Q1 舊決策（拖圖關卡，和 dial 收起一致）與新期望衝突。

## 原因

當年 dial 是扇形浮層，拖圖關是防擋視線；現在卡是錨定浮層，本就跟 move 快照追 pin，拖圖不脫鉤，舊理由失效。

## 修正

- 刪 `dragstart → setSelectedId(null)` 監聽；卡關閉只剩 X／換選另一 pin／登出（換選／登出沿舊不動）；工具列點地圖收起（URC1.3 C3）不動。
- UR2.1 凍結條目回寫改動記錄（AC2 邊界以本條為準）。
- 三閘綠；用戶瀏覽器覆蓋（開卡拖圖卡在＋跟走，X 關）。
