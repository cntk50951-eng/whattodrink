## round-4／DEF-008 真凶（2026-09-29，agent-browser 实证）

- 现象链：砖 valid＋complete 但渲染宽 0＋容器丢 `leaflet-container` 类＋钉／热自带尺寸故存活。
- 元凶：动态 className 绑在 Leaflet 拥有的 holder 节点上，首个 className 变化（heatOn）即重写抹类，瓦片 CSS 全灭。修法内外分家（外层动态，内层静态）。
- 铁律：React 动态 className 永不碰 Leaflet（及任何第三方）拥有的 DOM 节点；第三方加类只读不写。
- 另：agent-browser 只用于 debug 取证，不代替用户验收（本次截图即自证，亲验仍归用户）。

## 严重事故复盘（DEF-20260929-008，用户要求记死，2026-09-29）

- 现象：heat 一出现地图全白，修了三轮（回退→幂等→插件怀疑）全偏，险些把无辜的瓦片链重构了。
- 真凶：动态 className 绑在 Leaflet 拥有的节点上，首变即抹掉 `leaflet-container` 类。
- 为什么前三轮全偏：只看"逻辑层"（effect 顺序／回退／插件），没看"DOM 层"（实际 classList）。决定性证据来自浏览器实测（砖宽 0＋丢类），不是读码。
- 铁律 v2（与既有"注释只读不锚"并列）：① 第三方拥有的 DOM（Leaflet／地图／图表库容器）只挂静态类，动态态一律放祖先 wrapper；② 白屏类 bug 先看计算样式＋DOM 类，再读逻辑；③ 同一症状修两轮不中必须换取证手段（浏览器实测），禁第三轮盲猜。
