# 2026-09-05: UR1.1 地圖選型——Remotion 不做互動地圖

## 情境

UR1.1（新版）要求首頁是動態地圖，並點名「考慮是否可以使用 remotion 的元素」，
參考圖為 remotion.dev 官網截圖（粗黑描邊＋扁平高飽和藍綠＋貼紙傾斜卡）。

## 問題

Remotion 是 React 程序化視頻渲染框架（React → FFmpeg → MP4），不做即時互動地圖。
拿它的 runtime 渲染首頁地圖是錯誤選型：bundle 巨大、無互動、還要服務端渲染視頻。

## 原因

用戶要的是參考圖的「設計語言」，不是 Remotion 的「運行時」。
能借的只有兩樣：插畫語言（描邊／色塊／貼紙感）＋ spring 動畫手感。

## 修正

1. 未引入 remotion 依賴；設計語言用 CSS（紙色濾鏡＋塗鴉 pins／藥丸按鈕）＋ SVG 實現，
   動畫手感用 cubic-bezier(0.34,1.56,0.64,1) 彈簧曲線＋`prefers-reduced-motion` 降級。
2. 底圖用 Leaflet＋免費 CARTO Voyager raster（免 key，attribution 必留），
   用戶已確認此路線（另兩個候選：全手繪 SVG 示意圖、MapLibre 矢量——前者地理不可信，
   後者要 MapTiler key 且 GL canvas 難做手繪感）。
3. 之後任何「XX 庫能不能用」的點名要求，先查該庫的真實用途再決定借設計還是借運行時。
