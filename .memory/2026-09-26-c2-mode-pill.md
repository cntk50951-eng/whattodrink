# 2026-09-26 UR C.2 v2 模式選擇顯性化

## 情境

v2 右上模式入口是純圖標 Popover，用戶找不到（v1 DEF-001 同款可發現性問題重演）。建 UR C.2 補顯性入口。

## 問題

- 入口隱形：無文字標籤，用戶不知可點、不知當前模式。
- Popover 是浮層，心智重（點開一片）。

## 原因

- C.1 照 Snap 擺了圖標鈕，Snap 有頭像＋城市大標題襯托，v2 頂欄信息密度不同，直接抄位置不抄語境。
- v1 教訓（常駐 pill）在 C.1 未帶過來。

## 修正

- Popover 整組退役：常駐 pill（圖標＋當前模式文字，匿名顯通用態走登入）＋inline 三檔卡（絕對定位不擠佈局，選後自動收／再點收，登出自動收）。
- 零新 key（全複用 mode 命名空間）；共用層零改；v1 零文件。
- 三閘綠；用戶瀏覽器覆蓋（首屏可見＋切換落庫）。
