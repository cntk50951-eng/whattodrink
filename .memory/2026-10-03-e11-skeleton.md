# 2026-10-03 — E.11 打卡面板骨架（全套范围）

## 情境

- 用户 enhancement：打卡面板异步段未到之前要骨架 loading。留言区已有骨架，缺口在 Extra 整段＋他人图文。

## 问题

- 仓内无 `renderHook`／testing-library 先例，vitest 默认 node 环境无 DOM——hook `failed` 旗与骨架 JSX 无对应单测手段。
- 他人三件套只有 `otherDetailFor` ref 守卫，无 loading 旗；失败路径（!ok／catch／MOCK／切卡）不清旗即无限骨架。

## 原因

- testing.md 组件逻辑“视情况”＋用户偏好手动验收：纯视觉走浏览器亲验（含 DevTools 慢网＋断网两档），比硬写单测 ROI 高。
- ref 不触发渲染，loading 必须独立 state；且每个置真点必须有对称清旗点（开拉／落定／失败／切卡四处）。

## 修正

- `useCheckinDetail` 加 `failed`（加法返回；畸形包亦当失败）。
- Extra 三段式骨架（pills＋评分＋互动栏，同构防位移）；他人照片＋文字两段骨架；失败回落藏行。
- 三闸：tsc 零错／vitest 468 绿／lint 零错（5 警告 pre-existing）。
