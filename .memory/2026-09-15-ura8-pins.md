# 2026-09-15 UR A.8 地图 Pins 模糊坐标

## 情境
A.4-3 公开地图 Pins，需在服务端将他人精确坐标模糊到街区级（非前端藏），BBOX 过滤替掉 lib/checkins.ts MOCK。

## 问题
MOCK 数据在 lib/checkins.ts 为静态种子，无 DB、无 RLS、无模糊；直接暴露精确 lat/lng 违背 §7 公开隐隐私线。

## 原因
前端 MOCK 为 UR1.1 原型占位，EPIC2 A.4-3 需转真 DB 且服务端模糊。

## 修正
- lib/api/pins.ts：fuzzCoordinate（trunc 至 3 位小数，约 100m）、parseBbox（west,south,east,north 4浮点 + 越界/反向/面积≤2deg²）、parsePinsParams（limit 100/200）、toPinJson（校验 + 模糊 + isOnline 5min 窗 + users/beers join）、isBboxOverlapsHK
- app/api/v1/map/pins/route.ts：匿名公开读，复用 0005 RLS（checkins visibility=public），BBOX gte/lte + limit，直接模糊后返回，无新增 migration
- docs/api-openapi.yaml：新增 /api/v1/map/pins 路径 + MapPin/MapPinsPage schemas
- lib/api/pins.test.ts：11 单测（fuzz、parseBbox 4类、limit、toPinJson 映射/坏行/isOnline、overlap）
- 门：184 tests / build ✓ / lint 0 error（3 旧 warning）

## 教训
- 模糊必须 trunc 非 round（街区级验证要求可复现，不四舍五入导致跨街区漂移）
- 面积上限防全表扫（>2deg² 400），HK 全图约0.27deg² 正常 BBOX 可过
