# 2026-09-05 — UR1.5：扇形文字不可点的结构根因

## 情境
- UR1.5 原文三句：扇形子按钮右边文字无法点击，要求文字和按钮都能点。
- 当时扇形每行结构是外层 `div` ＋ 内层圆形 `<button>`（图标）＋ 纯展示 `<span>`（文字）。

## 问题
- 文字不在任何点击区里；直接给 `div` 加 onClick 会无键盘语义，
  且图标 button 的点击会冒泡触发两次；给文字 span 独立加 onClick
  则一格占两个 tab stop，键盘体验差。

## 原因
- 一行有两个视觉焦点但只有一个语义控件，结构本身就不对；
  在错误的结构上打补丁（div onClick / span onClick）只会引入新问题。

## 修正
- 整行改成单个 `<button>`（图标退为纯视觉 span，button 不可嵌套 button），
  one action / one tab stop，按压反馈用 `group-active:` 平移到圆形上。
- 经验：可点文字＋可点图标并排时，先问“是不是同一个 action”，
  是就合成一个控件，不要做两个可点元素。
