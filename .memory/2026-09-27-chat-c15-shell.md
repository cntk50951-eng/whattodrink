## 問題

1. `rtk npx ...` 被攔截為 `npm shadcn@latest`（"Unknown command"／"Missing script" 兩種報錯）。
2. 直調 npx 二進制又因 PATH 沒 export 跑成 node 18，undici 炸 `File is not defined`。
3. `shadcn add` 誤裝 `cn@^0.4.0` 依賴＋三文件 `from "cn"`（本站用 `@/lib/utils`）。

## 原因

1. rtk 把 `npx` 當 npm 子命令轉發；必須繞過 rtk 直調二進制全路徑。
2. npx shebang 走 `env node`，非交互 shell 默認 node 是 18；必須同行先 export Node 22 PATH。
3. 新版 CLI 不認 `components.json` 的 utils alias（或默認寫 `cn` 包），事後必 grep 驗。

## 修正

- 公式：`export PATH="/Users/yuki/.nvm/versions/node/v22.22.0/bin:$PATH" && /Users/yuki/.nvm/versions/node/v22.22.0/bin/npx --yes shadcn@latest add <name>`（本輪實證三次失敗後成功）。
- 裝完三驗：① `grep 'from "cn"' components/ui` ② `git diff package.json` 有無多餘依賴 ③ `tsc --noEmit`。
- 死依賴當場 `npm uninstall cn`（package.json/lock 回乾淨，實證）。
