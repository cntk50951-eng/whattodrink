# 2026-09-26 乾杯豁免加好友門、邀約加完即發（DEF-009 糾正）

## 情境

009 修完用戶糾正：乾杯應該除隱身外直過（加好友門只攔邀約）；公開邀約非好友加完能否直接約；隱身邏輯是否同樣。

## 問題

- 原實現連乾杯也攔（公開＋非好友彈層），與「乾杯是輕量打招呼」語義衝突。
- 加完（pending）能否約：等接受會死胡同（對方無接受 UI，只能靠互加）。

## 原因

- 第一版把「社交深度」一刀切：乾杯／邀約同等對待。實則乾杯＝輕量（like 級），邀約＝深互動（需關係）。
- 隱身是唯讀定義（三次拍板），乾杯在隱身必須攔——用戶問「隱身一樣嗎」答否，並說明理由，未重定義。

## 修正

- `handleCheers`：隱身彈層，其餘直過（關係分支整段刪）。
- 公開邀約非好友：層只剩加好友，加完 `onFriendAdded` 自動發邀約（卡不關，FX 可見）；friends 流程不動（收卡＋切換恢復）。
- 刪 `onProceed`＋`proceedCta` 死鍵（加完即發後無調用者）。
- 三閘綠；待用户复验（公開非好友乾杯直通／邀約加完即發／隱身全攔不動）。
