## 标注约定（四列）

每字段回答四问，缺一不可：

1. **页面位置**：用户在哪里看到／用到
2. **类型**：TS 类型（`lib/` 有定义的写全名）
3. **当前来源**：`state`（会话）／`localStorage(key)`／`mock`／`外部 API`／`静态`
4. **未来表映射**：EPIC 3.0 进哪张表的哪个字段，或明确标 `不进库`

## 更新规则

见 `.harness/workflow.md` Step 9b：每次功能／增强改动后检查本目录是否要同步。
规则只有一条：**新增／改变了前端展示或使用的数据，就同步改文档**；
纯 UI 位移、纯文案、不改数据的重构不用动。
