# 酒类分类总纲（UR2.3 类别先行，品牌随后）

世界酒类、全覆盖 HK 年轻人常喝。每个子类都是未来 `beers.category` 的候选值；
品牌文件（`01–10`）按此纲归位，缺类的品牌后续补进对应新文件。

## 一、啤酒（发酵＋风格）

- 拉格：美式淡拉格／国际淡拉格／皮尔森（德／捷）／慕尼黑清亮／深色拉格／
  维也纳／三月／博克／双博克／冰博克／冰酿／无醇拉格
- 淡艾与 IPA：英式苦啤／美式淡艾／美式 IPA／双 IPA／三 IPA／hazy IPA／
  黑 IPA／酸 IPA／奶昔 IPA／冷 IPA／英式 IPA
- 波特与世涛：波特／干世涛／牛奶世涛／燕麦世涛／帝世／桶陈世涛／
  糕点世涛／牡蛎世涛／俄罗斯帝世
- 英式传统：棕艾／ mild／老艾尔／大麦酒／苏格兰艾尔（60–90 先令）／
  英式大麦酒／ Burton Ale
- 小麦：德式小麦／水晶小麦／小麦博克／比利时白啤／美式小麦／柏林酸小麦／
  粗磨谷物艾尔（gruit 方向）
- 比利时修道院：双料／三料／四料／金色烈艾／深色烈艾／Trappist 认证体系／
  Abbey（非认证修道院风）
- 比利时特色：季节（标准／深色／野菌）／比利时金艾／比利时深艾／
  圣诞啤酒／蜂蜜啤酒
- 酸与野菌：柏林酸／果斯（传统／水果）／兰比克（自然／老）／
  樱桃兰比克／覆盆子兰比克／法柔／ Flanders 红艾／ oud bruin／
  美式野菌艾尔／桶陈酸啤
- 烟熏与黑麦：班贝格烟熏／黑麦 IPA／黑麦世涛
- 特色与实验：水果啤酒／香料草本／咖啡巧克力／蜂蜜酒 braggot 方向／
  葡萄艾尔（Italian Grape Ale）／牡蛎世涛
- 替代与低干预：无麸质／无醇啤酒／低碳水淡啤／康普茶酒／硬苏打／硬茶／
  含 CBD（地区限定，备查）

## 二、葡萄酒（颜色＋工艺＋品种）

  国产多瑞加／黑珍珠（nero d'avola）／阿利亚尼科／ Montepulciano
- 白：霞多丽／长相思／雷司令／灰皮诺／琼瑶浆／维欧尼／白诗南／赛美蓉／
  莫斯卡托／阿尔巴利诺／绿酒／特雷比奥罗／ Vermentino／小满胜
- 桃红：普罗旺斯桃红／西班牙 rosado／意大利 chiaretto／黑皮诺桃红／
  起泡桃红
- 橙酒（带皮发酵白）：格鲁吉亚 qvevri／意大利／斯洛文尼亚／新世界
- 起泡：香槟（年份／无年份／白中白／黑中白／桃红）／卡瓦／普罗塞克／
  阿斯蒂／ Franciacorta／德国塞克特／ Pet-Nat／新世界传统法起泡／
  transfer 法／罐中二次发酵
- 加强：波特（宝石／茶色／年份／单一年份／白波特）／雪莉
  （菲诺／曼萨尼亚／阿蒙蒂亚多／奥罗索／PX／ cream)／马德拉／
  马沙拉／ Banyuls
- 甜：贵腐（苏玳／托卡伊阿苏）／冰酒／晚收／稻草酒／PX 甜雪莉／
  莫斯卡托阿斯蒂／冰红
